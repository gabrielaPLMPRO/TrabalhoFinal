# Prompts do projeto

Prompts enviados pelo usuário, preservados como referência para próximas etapas:

1. [Refatoração, diagnóstico e evolução de código](01_REFATORACAO_DIAGNOSTICO_EVOLUCAO.md).
2. [Criação de issues e plano de commits coesos](02_ISSUES_COMMITS_COESOS.md).

Os textos registram as solicitações originais. O segundo chegou com o template final incompleto; essa limitação está indicada no arquivo.

Para retomar o projeto, consultar também o [diagnóstico e histórico do processo](../DIAGNOSTICO_REFATORACAO.md) e o [plano de issues e commits](../PLANO_ISSUES_COMMITS.md), além do estado atual do Git e das issues. Os prompts não substituem esses registros de execução.
